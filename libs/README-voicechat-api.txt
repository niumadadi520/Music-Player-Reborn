voicechat-api-2.6.20.jar is an unmodified compile-time dependency obtained from
the Simple Voice Chat author's Maven repository. It is used by the karaoke
integration and is deliberately excluded from the mod's runtime JAR.

API documentation and source project:
https://modrepo.de/minecraft/voicechat/api/overview
https://github.com/henkelmax/simple-voice-chat

The game runtime needs the separate Simple Voice Chat Forge mod on the server,
singer and listeners. The compatibility version verified for this release is
Forge 1.20.1-2.6.23, which supplies API version 2.6.20.

No Simple Voice Chat implementation is repackaged into MengSama Net Music.
